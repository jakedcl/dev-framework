# Launch checklist

- [ ] Domain ownership confirmed and email records untouched. → [domains.md](../hosting/domains.md)
- [ ] `www` and `http` both 301 to the apex; HTTPS and HSTS on. → [domains.md](../hosting/domains.md)
- [ ] Hosting plan allows commercial use. → [vercel.md](../hosting/vercel.md), [cloudflare.md](../hosting/cloudflare.md)
- [ ] Leads go to the client's inbox, sent from the client's own domain. → [email.md](../building/email.md)
- [ ] Forms are idempotent, show Sent only after a confirmed send, pass the form-path harness, and none still says "not connected yet." → [forms.md](../building/forms.md), [testing.md](../working/testing.md)
- [ ] OG tags and image, titles, robots.txt, sitemap, a real 404, Search Console, and the Business Profile if local. → [seo-launch.md](../hosting/seo-launch.md)
- [ ] No placeholder or unconfirmed content live. → [design.md](../building/design.md)
- [ ] Privacy policy, accessibility statement and form consent line live (restaurants: allergy line and raw advisory). → [legal.md](../building/legal.md)
- [ ] Studio client-proofed: limits, required fields, locked pages, protected photos. → [sanity.md](../building/sanity.md)
- [ ] Test users, posts and uploads deleted. → [testing.md](../working/testing.md)
- [ ] No tokens in public env vars, and payments out of sandbox only if real orders are intended. → [security.md](../building/security.md)
- [ ] Uptime monitor added, with alerts to jake@dcldev.com, and failed builds alert Jake. → [monitoring.md](../hosting/monitoring.md)
- [ ] Real check on desktop and a real phone. → [testing.md](../working/testing.md)
- [ ] Client OK to feature the site in the portfolio. → [clients.md](../working/clients.md)
- [ ] After launch: listings sweep sent to the client as one fix list. → [seo-launch.md](../hosting/seo-launch.md)
