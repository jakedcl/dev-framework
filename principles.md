# Principles

The ideas every other file follows. Read these first.

- **Free or cheap by default.** Stay on free tiers until a client pays for more. Why: it's how Jake runs the agency. (Jake)
- **Grow the agency.** A rule belongs here only if it makes client work faster, safer or more professional on any project. Why: this isn't a record of one site's taste. (Jake, Oct 25, 2026)
- **Only always-true rules.** If the answer depends on the situation, it's a short "How to decide" note or it's left out. Why: rules that are too detailed get misapplied. (Jake, Oct 25, 2026)
- **Tool-neutral.** Plain markdown that any AI tool or person can follow. Why: Jake uses many tools. (Jake)
- **Short sources.** Each rule names where it came from in a few words, and the full story lives in the PR that added it. Why: a rule without its story gets ignored, but long stories bury the rule.
- **Approval before it lands.** Changes here go in as PRs that Jake approves. Why: Jake decides what the framework says, so nothing lands on main without his OK.
